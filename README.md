# Software Engineering Learning

**Learn how software is created in a company — one small step at a time.**

This course is for a beginner. You can study it on your mobile phone. You do not need a laptop, and you do not need to write code for every lesson.

## Our one project

We will learn using a small imaginary app called **Campus Help Desk**.

Students use it to report problems at university. Staff use it to solve them.

Example: A student reports that a classroom projector is broken. Staff receive the report and update its status.

We will follow this same project from the first idea to release and maintenance.

## How I will teach you

Every lesson will be:
- Short: about 5–10 minutes.
- Written in simple English.
- About one main idea.
- Explained with an easy example.
- Connected to our project.
- Finished with a few quick questions and answers.

No unnecessary advanced words. When a technical word is important, I will explain it simply.

## Our journey

1. Understand the problem.
2. Learn what users need.
3. Plan how the app should work.
4. Understand how a software team works.
5. Learn how developers build it.
6. Understand how information is saved.
7. Check that the app works.
8. Release it for users.
9. Maintain and improve it.

## Remember

This repository teaches **general Software Engineering**. Java, APIs, databases, Git, and GitHub are examples that help explain the work. They are not the main course.

Study one small lesson whenever you have free time. You do not need to rush.
