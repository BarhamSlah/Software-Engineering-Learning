# Who Works in a Software Company?

**Time:** 6 minutes · **Level:** Beginner

## 1. The idea

A software product is usually made by people with different responsibilities.

## 2. Common roles

| Role | Simple job |
|---|---|
| Customer / user | Explains what they need |
| Product manager | Helps decide what the team should build first |
| Business analyst | Helps understand and write requirements |
| Designer | Plans how the product looks and feels to use |
| Developer | Builds the software |
| Tester / QA | Checks that it works correctly |
| DevOps / platform engineer | Helps release and run the software |

One person may do several jobs in a small company. Every company is not organized in exactly the same way.

## 3. Our project example

For Campus Help Desk:
- Students explain the problem they face.
- A product manager decides which improvements matter most.
- A designer plans the screens.
- Developers build the app.
- A tester checks the report process.
- The operations team helps release it.

## 4. Remember this

**A software company works as a team. Developers are important, but they are not the only people involved.**

## 5. Quick check

Who checks whether the app works as expected?

**Answer:** A tester or QA engineer, often together with developers.
