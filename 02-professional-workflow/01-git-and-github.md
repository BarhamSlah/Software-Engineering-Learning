# Git and GitHub

**Time:** 5 minutes · **Level:** Beginner

## 1. The idea

**Git** remembers changes to project files.

**GitHub** is a website where people can store Git projects and work together.

## 2. Simple example

Imagine two developers are working on the Campus Help Desk app.

Git helps them track what changed.

GitHub helps them share the project and review each other's work.

## 3. Remember the difference

| Git | GitHub |
|---|---|
| A tool on your computer | An online platform |
| Tracks file changes | Hosts projects and supports teamwork |
| Has commits and branches | Has Pull Requests and reviews |

## 4. Useful words

- **Repository:** the project and its history.
- **Commit:** a saved record of changes.
- **Branch:** a separate line of work.
- **Push:** send commits to GitHub.
- **Pull Request:** ask the team to review a change.

## 5. Remember this

**Git tracks changes. GitHub helps people share and work together.**

## 6. Quick check

Is GitHub the same thing as Git?

**Answer:** No. Git is the version-control tool; GitHub is a platform that uses Git.
